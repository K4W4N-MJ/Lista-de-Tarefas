# 📋 Lista de Tarefas (To‑Do List)

Projeto simples de **Lista de Tarefas** desenvolvido com **HTML, CSS e JavaScript puro**, focado em praticar manipulação do DOM, eventos e uso do **localStorage** para persistência de dados no navegador.

---

## 🧠 Sobre o projeto

A aplicação permite adicionar, listar e remover tarefas de forma dinâmica. As tarefas são salvas automaticamente no navegador, garantindo que não sejam perdidas ao atualizar a página.

Esse projeto foi criado com fins de **aprendizado prático em Front‑End**, reforçando conceitos essenciais da base do JavaScript.

---

## 🚀 Funcionalidades

* Adicionar novas tarefas
* Remover tarefas individualmente
* Salvar tarefas no localStorage
* Carregar tarefas salvas ao abrir a página
* Interface simples e objetiva
* Botões com efeito visual e hover

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* localStorage

---

## 🧩 Como funciona

1. O usuário digita uma tarefa no campo de texto
2. Ao clicar em **Adicionar Tarefa** ou pressionar **Enter**, a tarefa é criada
3. Cada tarefa recebe um botão **Apagar**
4. As tarefas são salvas automaticamente no localStorage
5. Ao recarregar a página, as tarefas são restauradas

---

## 💾 Persistência de dados

O projeto utiliza o `localStorage` do navegador para armazenar as tarefas em formato JSON, garantindo que os dados permaneçam mesmo após fechar ou atualizar a página.
